# seqera_studios_list (Data Source)

Data source for listing Studios in a Seqera Platform workspace.

Returns the Studios in a workspace, optionally filtered with `search`.
The platform returns at most 100 Studios per request; `total_size` reports
how many match so truncation can be detected. Use Terraform locals with
for expressions to look up a Studio by name.

## Example Usage

```terraform
# List the Studios in a workspace
data "seqera_studios_list" "all" {
  workspace_id = seqera_workspace.main.id
}

# Narrow the result server-side. Free text matches the Studio name and tool
# image URL. Keywords such as `status:running` are also supported; see
# data-source_filters.tf.
data "seqera_studios_list" "jupyter" {
  workspace_id = seqera_workspace.main.id
  search       = "jupyter"
}

# The platform returns at most 100 Studios per request. Fail early if the
# result was truncated rather than silently missing Studios.
check "studios_not_truncated" {
  assert {
    condition     = data.seqera_studios_list.all.total_size <= length(data.seqera_studios_list.all.studios)
    error_message = "More Studios exist than were returned; narrow the query with `search`."
  }
}

# Look up a Studio by name
locals {
  studios_by_name = {
    for s in data.seqera_studios_list.all.studios : s.name => s
  }
}

output "analysis_studio_session_id" {
  value = local.studios_by_name["my-jupyter-studio"].session_id
}
```

### Filters

```terraform
# `search` filters on the server. Besides free text (matched against the Studio
# name and tool image URL) it understands `keyword:value` filters: `userName`,
# `computeEnvName`, `computeEnvType`, `status`, `label`, `collaborationMode` and
# the `createdAfter`, `createdBefore`, `updatedAfter` and `updatedBefore` dates.
# `status` is one of starting, running, stopping, stopped, errored, building or
# buildFailed. Combine filters by separating them with spaces.
data "seqera_studios_list" "on_compute_env" {
  workspace_id = seqera_workspace.main.id
  search       = "computeEnvName:${seqera_compute_env.main.name}"
}

data "seqera_studios_list" "running" {
  workspace_id = seqera_workspace.main.id
  search       = "status:running"
}

# Filter further in Terraform, for example private Studios built by Wave
locals {
  private_custom_image_studios = [
    for s in data.seqera_studios_list.on_compute_env.studios : s.name
    if s.is_private && s.custom_image
  ]
}

output "studios_on_compute_env" {
  value = {
    total = data.seqera_studios_list.on_compute_env.total_size
    names = [for s in data.seqera_studios_list.on_compute_env.studios : s.name]
  }
}
```
