# seqera_studio_templates (Data Source)

Data source for listing the Studio templates available on the Seqera Platform.

Each template is a tool container image that can be used as the
`data_studio_tool_url` of a `seqera_studios` resource. Use Terraform locals
with for expressions to select a template by tool and support status.

The available templates are configured per Platform deployment, so the list
differs between Seqera Cloud and self-hosted installations.

## Example Usage

```terraform
# List the Studio templates configured on the platform. The available templates
# are set per Platform deployment, so they differ between installations.
data "seqera_studio_templates" "all" {
  workspace_id = seqera_workspace.main.id
}

# Pick the recommended image for a tool instead of hard-coding its version
locals {
  recommended_templates = {
    for t in data.seqera_studio_templates.all.templates : t.tool => t.repository
    if t.status == "recommended"
  }
}

resource "seqera_studios" "jupyter" {
  name                 = "my-jupyter-studio"
  compute_env_id       = seqera_compute_env.main.id
  workspace_id         = seqera_workspace.main.id
  data_studio_tool_url = local.recommended_templates["jupyter"]

  configuration = {}
}
```

### Nested Schema for `templates`

Read-Only:

- `icon` (String) Icon identifier for the tool
- `repository` (String) Container image URL of the template. Use as `data_studio_tool_url` when creating a Studio.
- `status` (String) Support status of the template. One of `recommended`, `deprecated`, `experimental` or `unsupported`.
- `tool` (String) Tool the template provides (for example `jupyter`, `ride`, `vscode` or `xpra`; `custom` when not set)
