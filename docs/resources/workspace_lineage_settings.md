# seqera_workspace_lineage_settings (Resource)

Manage the lineage settings of a Seqera workspace.

Lineage records how data and runs relate to each other. In `AUTO` provisioning mode Platform creates the storage bucket, notification topic and subscription; in `MANUAL` mode you pre-create the bucket and topic and subscribe the `webhook_url` to the topic.

~> **Note:** Destroying this resource disables lineage for the workspace. AWS infrastructure (bucket, topic, subscription) is left intact.

## Example Usage

```terraform
# Use one of the two configurations below per workspace: exactly one resource
# may manage a given workspace's lineage settings, so the AUTO and MANUAL
# examples use different workspaces.
# var.* and seqera_aws_credential.main are placeholders for your own values.
#
# AUTO provisioning (default): Platform creates the lineage bucket, the
# notification topic and the subscription. Do not set store_name or topic_arn.
#
# credentials_id and region are locked once AUTO provisioning has completed; changing
# them afterwards is rejected by the Platform.
#
# Destroying this resource disables lineage for the workspace. The AWS
# infrastructure that was created is left in place.
resource "seqera_workspace_lineage_settings" "auto" {
  org_id            = var.auto_org_id
  workspace_id      = var.auto_workspace_id
  provisioning_mode = "AUTO"

  credentials_id  = seqera_aws_credential.main.id
  region          = "eu-west-1"
  lineage_default = true
}

# MANUAL provisioning: you create the bucket and the SNS topic, and subscribe
# the Platform webhook to the topic. store_name and topic_arn are required.
resource "aws_sns_topic" "lineage" {
  name = "seqera-lineage-events"
}

resource "seqera_workspace_lineage_settings" "manual" {
  org_id            = var.manual_org_id
  workspace_id      = var.manual_workspace_id
  provisioning_mode = "MANUAL"

  credentials_id = seqera_aws_credential.main.id
  region         = "eu-west-1"
  store_name     = "my-existing-lineage-bucket"
  topic_arn      = aws_sns_topic.lineage.arn
}

# The subscription is confirmed by the Platform. event_delivery stays
# PENDING_CONFIRMATION until the confirmation completes.
resource "aws_sns_topic_subscription" "lineage" {
  topic_arn = aws_sns_topic.lineage.arn
  protocol  = "https"
  endpoint  = seqera_workspace_lineage_settings.manual.webhook_url
}
```

## Schema

### Required

- `credentials_id` (String) Credentials ID used to create and access the lineage storage bucket.
- `org_id` (Number) Organization numeric identifier. Requires replacement if changed.
- `region` (String) Cloud region where the lineage storage bucket will be created (e.g. 'us-east-1').
- `workspace_id` (Number) Workspace numeric identifier. Requires replacement if changed.

### Optional

- `lineage_default` (Boolean) When true, the lineage toggle in the pipeline launch form defaults to enabled. Default: false
- `provisioning_mode` (String) How the lineage infrastructure is provisioned. AUTO: Platform creates the bucket, SNS topic and subscription. MANUAL: you pre-create the bucket and SNS topic and subscribe the Platform webhook (see `webhook_url`) to the topic yourself. Default: "AUTO"; must be one of ["AUTO", "MANUAL"]
- `store_name` (String) Bucket name for the lineage store. Must not be set in AUTO mode, where Platform selects the bucket `seqera-lineage-{workspaceId}`; required in MANUAL mode and must match the existing bucket.
- `topic_arn` (String) AWS only. ARN of the SNS topic receiving the bucket's S3 notifications. Required in MANUAL mode; not accepted in AUTO mode.

### Read-Only

- `event_delivery` (String) Whether object events are being delivered to Platform: NOT_CONFIGURED, PENDING_CONFIRMATION, ACTIVE or FAILED.
- `message` (String) Error message when status is ERRORED.
- `provisioned` (Boolean) Whether the lineage infrastructure has been provisioned for the workspace.
- `status` (String) Lifecycle status of the lineage configuration: PENDING, AVAILABLE or ERRORED. Null when lineage is not configured.
- `webhook_url` (String, Sensitive) Endpoint the cloud provider delivers object events to. In MANUAL mode, subscribe this URL to your topic.
