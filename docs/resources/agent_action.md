# seqera_agent_action (Resource)

Manage an action that runs a Seqera agent when it triggers.

An agent action watches a bucket, a schedule or the status of a
pipeline's runs, and runs the `seqera_agent` named by
`agent_id` each time it fires. The agent must be active.
To launch a pipeline instead, use `seqera_pipeline_action`.

Migrating from `seqera_action`: an action created with
`response_type = "agent"` can be moved here without recreating it,
using a `moved` block (Terraform 1.8+).

## Example Usage

```terraform
# Runs an agent each time a run of the watched pipeline fails. The agent runs
# as a service account, which must be a workspace participant with a role that
# allows launching agents.
resource "seqera_service_account" "triage" {
  org_id = seqera_workspace.main.org_id
  name   = "run-triage"
}

resource "seqera_workspace_participant" "triage" {
  org_id       = seqera_workspace.main.org_id
  workspace_id = seqera_workspace.main.id
  member_id    = seqera_service_account.triage.member_id
  role         = "launch"
}

resource "seqera_agent" "triage" {
  workspace_id       = seqera_workspace.main.id
  name               = "failed-run-triage"
  agent_instructions = "Read the logs of the failed run, summarise the root cause and suggest a fix."
  service_account_id = seqera_service_account.triage.id

  depends_on = [seqera_workspace_participant.triage]
}

resource "seqera_agent_action" "triage_on_failure" {
  workspace_id = seqera_workspace.main.id
  name         = "triage-failed-runs"
  source       = "pipeline_status"
  agent_id     = seqera_agent.triage.id

  pipeline_status = {
    pipeline_id = seqera_pipeline.upstream.pipeline_id
    run_status  = "FAILED"
  }
}
```

### Bucket Trigger

```terraform
# Runs an agent when the marker file appears in the watched data link.
resource "seqera_agent_action" "on_upload" {
  workspace_id = seqera_workspace.main.id
  name         = "check-new-uploads"
  source       = "bucket"
  agent_id     = seqera_agent.qc.id

  bucket = {
    data_link_id = seqera_data_link.inputs.data_link_id
    marker_file  = "ready.txt"
  }
}
```

### Cron Schedule

```terraform
# Runs an agent every weekday at 08:00 Madrid time.
resource "seqera_agent_action" "daily_report" {
  workspace_id = seqera_workspace.main.id
  name         = "daily-run-report"
  source       = "cron"
  agent_id     = seqera_agent.reporter.id

  cron = {
    expression = "0 8 * * 1-5"
    timezone   = "Europe/Madrid"
  }
}
```

### Moved From Action

```terraform
# Moves an agent action managed by seqera_action (response_type = "agent") to
# seqera_agent_action without recreating it. Requires Terraform 1.8 or later.
# Replace the seqera_action block with the seqera_agent_action one:
# agent.agent_config_id becomes agent_id, and response_type goes away.
moved {
  from = seqera_action.triage_on_failure
  to   = seqera_agent_action.triage_on_failure
}

resource "seqera_agent_action" "triage_on_failure" {
  workspace_id = seqera_workspace.main.id
  name         = "triage-failed-runs"
  source       = "pipeline_status"
  agent_id     = seqera_agent.triage.id

  pipeline_status = {
    pipeline_id = seqera_pipeline.upstream.pipeline_id
    run_status  = "FAILED"
  }
}
```

## Schema

### Required

- `agent_id` (String) ID of the `seqera_agent` to run. Requires replacement if changed.
- `name` (String) Name of the action.
- `source` (String) Event source that triggers the action. must be one of ["bucket", "cron", "pipeline_status"]; Requires replacement if changed.
- `workspace_id` (Number) Workspace numeric identifier. Requires replacement if changed.

### Optional

- `bucket` (Attributes) Bucket trigger. Fires when the marker file appears under the data link. Required when `source` is `bucket`; must not be set otherwise. (see [below for nested schema](#nestedatt--bucket))
- `cron` (Attributes) Cron trigger. Fires on a schedule. Required when `source` is `cron`; must not be set otherwise. Set either `expression` or `preset`. (see [below for nested schema](#nestedatt--cron))
- `label_ids` (List of Number) IDs of the labels to attach to the action. Removing this attribute leaves the current labels in place.
- `pipeline_status` (Attributes) Pipeline-status trigger. Fires when a run of the watched pipeline reaches `run_status`. Required when `source` is `pipeline_status`; must not be set otherwise. (see [below for nested schema](#nestedatt--pipeline_status))

### Read-Only

- `error` (String) Error reported by the Platform for the action, if any.
- `id` (String) Action identifier.
- `next_execution` (String) Next scheduled run of a `cron` action.
- `status` (String) Current status of the action.
