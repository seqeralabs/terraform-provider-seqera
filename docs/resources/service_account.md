# seqera_service_account (Resource)

Manage a service account in a Seqera organization. A service account
is a non-human identity that agents run as.

To use it, add it to a workspace with `seqera_workspace_participant`
(`member_id = seqera_service_account.x.member_id`) using a role that
allows launching agents, then bind it to an agent with
`seqera_agent.service_account_id = seqera_service_account.x.id`.

Deleting a service account removes it from every workspace. The
platform then disables every agent bound to it and pauses every action
that targets those agents. Terraform does not show these side effects
in a plan.

Requires service accounts to be enabled on the Platform instance.

## Example Usage

```terraform
# A service account is an organization-level identity for agents.
resource "seqera_service_account" "ci" {
  org_id      = var.org_id
  name        = "ci-agent"
  description = "Identity for agents triggered by CI pipelines"
}

# Add it to a workspace so agents there can run as it. The role must allow
# launching agents: `launch`, `maintain`, `admin` and `owner` do, while
# `connect` and `view` (the default for service accounts) do not.
resource "seqera_workspace_participant" "ci" {
  org_id       = var.org_id
  workspace_id = var.workspace_id
  member_id    = seqera_service_account.ci.member_id
  role         = "launch"
}
```

## Schema

### Required

- `name` (String) Service account name: 2 to 39 lower-case letters, digits and single dashes, starting and ending with a letter or digit. Names are unique across the whole platform, not only the organization; a name already in use fails the apply with a conflict.
- `org_id` (Number) Organization numeric identifier. Requires replacement if changed.

### Optional

- `description` (String) Description of the service account, up to 1000 characters.

### Read-Only

- `created_at` (String) Creation timestamp.
- `id` (Number) Service account numeric identifier (the account's user id). Use it as `seqera_agent.service_account_id`.
- `member_id` (Number) Organization membership identifier of the service account. Use it as `seqera_workspace_participant.member_id` to add the account to a workspace.
